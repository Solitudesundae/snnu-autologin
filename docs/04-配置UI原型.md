## 配置窗体（首次运行自动弹出 / 托盘双击打开）

```
╔══════════════════════════════════════════════╗
║ 陕师大校园网自动认证 · 配置            [—][□][×] ║
╠══════════════════════════════════════════════╣
║ 填写校园网认证信息（与门户登录页一致）           ║
║                                              ║
║ 学号：    [ 20231001___________________ ]     ║
║           └错误态: "请输入学号" 红色感叹号      ║
║                                              ║
║ 密码：    [ ●●●●●●●●___________________ ]     ║
║           占位符: 已配置→"（已保存，留空不修改）" ║
║                    未配置→"统一身份认证密码"      ║
║           校验: 不可含分号(;，门户限制)          ║
║                                              ║
║ 服务类型： [ 中国联通                    ▼]     ║
║            ├ 校园网（免费 2.5G/月）             ║
║            ├ 中国联通        ← 默认             ║
║            ├ 中国移动                           ║
║            └ 中国电信                           ║
║                                              ║
║           [✓] 开机自动启动并检测                ║
║                                              ║
║ 密码仅以 Windows 加密（DPAPI）保存在本机，       ║
║ 不会明文存储或上传。                            ║
║ 已配置过密码时，密码框留空表示不修改。            ║
║                                              ║
║              [ 保存并检测 ]  [ 取消 ]           ║
╚══════════════════════════════════════════════╝
```

交互说明：

1. **保存并检测**：校验通过 → DPAPI 加密落盘 → 注册/注销自启动 → 触发一轮检测（立即验证新凭据）。
2. **熔断恢复**：密码错误熔断后托盘常灰并弹此窗；保存新凭据自动解除熔断。
3. **首次运行**：检测发现未认证且无配置时自动弹出；用户取消也可稍后从托盘进入。

## 状态气泡示例

| 场景 | 气泡 |
|---|---|
| 自动登录成功 | ℹ `校园网已连接` / `自动登录成功，剩余流量 2635.9 MB。` |
| 密码错误 | ⚠ `登录失败` / `账号或密码错误，已停止自动重试，请检查配置。` |
| 门户要求验证码 | ⚠ `需要验证码` / `门户要求输入验证码，请在打开的登录页中手动登录一次。` |
